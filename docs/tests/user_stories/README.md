# User Stories

These are sets of actions that the user would use to accomplish a specified goal. These are
described here to serve as a base for emulator tests. The tests and acceptance criteria are
written using the Gherkin language, a reference is given by Cucumber [here](https://cucumber.io/docs/gherkin/reference)
and also a good reference is [this](https://ftp.fau.de/cran/web/packages/cucumber/vignettes/reference-gherkin.html) Gherkin Reference.
To create new stories, use the [create folder story](CREATE_FOLDER.md) as a template.
